# 專案地下城

外掛式的行為介入輔助系統。不干涉既有課程內容，把專案管理（時間預估、
風險防禦、復盤反思）轉化為 8-bit 像素風格的地下城探險。

```bash
node v2/serve.js     # http://localhost:8792
node v2/build.js     # src/ → index.html
node v2/check.js     # 殘留檢查：明確不要的東西有沒有偷偷長回來
```

## 核心循環

老師派里程碑 → 學生拉滑桿**自己承諾天數** → 每日點「推進」→ 走到終點上傳
→ 系統比對承諾與實際，蓋 🎯 / 🚀 / ❌ → 失準就到營火點圖示標籤說卡在哪
→ 老師看完發**裝備**（資訊性回饋，不是分數）→ 大躍進。

## 三根柱子（SDT）

| | 怎麼做到 |
|---|---|
| **自主性** | 期限由學生自己拉滑桿決定。系統裡沒有任何一個地方由老師訂天數。 |
| **勝任感** | 判定的是**預估準度**，不是作業好壞。失準不扣任何東西，坦誠反思照樣拿裝備。 |
| **關聯性** | 沒有排行榜。全班地下城生態圖，看得到別人也在挖，但不比較。 |

## 承接自前一個作品

視覺 DNA 完整繼承（Cubic 11、11 的倍數字級、CSS 變數、24×16 像素圖、
切角按鈕）、40 隻魔物與 24 件裝備的像素圖、每組不同魔物的雜湊算法、
帳號／班級／名冊模型。詳見 `地心圖鑑-視覺規格書.md`。

分數、排名、收集圖鑑、四層固定課綱全部拿掉——那些跟這個作品的
獎勵哲學相反。`v2/check.js` 負責擋它們長回來。
